# MOONS 플래너 — 조사와 개선안 (2026-11-09)

방향: **MOONS 플래너는 각자가 쓰는 다이어리 웹**이고, 그 안의 **플래너 문(에이전트)**과 사용자가 이미 쓰는 **Claude**가 대화 속에서 플래너를 쉽게 만들고 고치게 돕는다. 기록은 생활 데이터 허브에 쌓여 MOONS·모의 우주·에너지긴축모드로 이어진다.

**결론:** "대화로 만들고 + 다꾸처럼 꾸미고 + 하루 기록이 목표·분석·다른 서비스로 이어지는" 조합은 찾지 못했다. 가장 가까운 건 xTiles(블록 + AI + Claude 커넥터)와 다꾸 앱들(꾸미기). MOONS 플래너의 자리는 **둘 사이**다.

## 2. 다꾸 레퍼런스에서 배울 것

- **Zinnia**: 마스킹테이프 컬렉션이 가장 호평. 실행 취소, 크기 조절, 앞·뒤 보내기, 레이어 잠금, 자르기, 회전, 직접 그린 스티커. 아이폰 지원과 구독 가격은 불만. ([WhistleOut 리뷰](https://www.whistleout.com/CellPhones/Apps/zinnia-app-review), [스티커 만들기](https://support.pixiteapps.com/hc/en-us/articles/32297292994067-Create-Stickers))
- **자꾸다꾸**(국내): 연필·크레용·펜으로 쓰기, 스티커 잘라 꾸미기, **손글씨 폰트 250개 이상 무료**, 작가 브랜드 다이어리·스티커 500개 이상 스토어, 내가 만든 스티커 판매.
- **Hibi Calendar**: 하루 = 종이 한 장. 사진에서 피사체만 오려 스티커, 카메라로 찍은 질감을 마스킹테이프 롤로. 캘린더·미리 알림을 불러와 다시 입력하지 않음. ([소개글](https://maily.so/whattheapp/posts/w6ovpndyok5))
- 공통: **글꼴 수와 스티커·테이프의 양**이 만족도를 정하고, **자유 배치(겹치기·회전·레이어)**가 기본이다.

## 4. 다음 개선안 (제안, 아직 안 함)

### 4.1 다꾸 재료 늘리기
1. **스티커 팩**: 이모지 대신 직접 그린 SVG 스티커 세트(문구류·날씨·음식·동물·별) 200개부터. 계절 팩.
2. **사진 → 스티커**: 사진에서 피사체만 오리기(브라우저 안 배경 제거 모델, 서버 비용 없음). Hibi의 핵심 기능.
3. **나만의 테이프**: 사진 한 장을 반복 무늬 테이프로.
4. **손글씨 펜**: 위젯 위에 펜으로 긋기(애플펜슬·터치), 형광펜.
5. **폰트 더**: 지금 33종 → 눈누 등 상업 이용 가능한 무료 한글 폰트를 직접 올려 60종 이상. 사용자가 자기 폰트 파일 올리기.

### 4.2 배치의 자유
1. **자유 배치 모드**: 지금은 12칸 격자 + 꾸미기만 자유. 위젯 자체도 격자 없이 픽셀 단위로 두는 모드(다꾸 앱처럼). 휴대폰은 따로 배치를 저장.
2. **페이지 여러 장**: 하루 페이지 외에 "주간 다꾸", "월간 표지", "버킷리스트"처럼 사용자가 만드는 페이지. 주간·달력·목표 탭도 같은 위젯 편집기로.
3. **표지·속지**: 다이어리 표지와 월 구분 속지. 날짜를 넘기면 종이를 넘기는 느낌.
4. **레이어 잠금, 정렬 도우미(가이드선)**, 위젯 묶기.

### 4.3 템플릿 공유와 마켓
- 사용자가 만든 배치+스킨을 템플릿으로 저장하고 링크로 공유, 나중에 작가 템플릿·스티커 판매(자꾸다꾸 모델).

### 4.4 플래너 문(에이전트)
- 다이어리 웹 안의 대화창: "이번 주 시험 기간 페이지 만들어 줘" → 위젯·스킨 제안 → 미리보기 → 적용. 지금 Claude 커넥터와 같은 `build_planner`를 쓰므로 둘의 결과가 같다.
- 하루 끝에 기록을 보고 "내일 계획"을 제안(현실 가용 시간·컨디션 기준), 사용자가 고르면 데일리에 올림.

## 5. Claude 커넥터 (만들었고 배포됨)

- **연결:** claude.ai → 설정 → 커넥터 → 커스텀 커넥터 추가 → URL `https://planner-production-1394.up.railway.app/mcp` → 플래너의 연결 허락 화면에서 MOONS 계정으로 로그인 후 "연결하기".
- **Claude가 할 수 있는 것:**
  - `planner_guide`: 만드는 순서와 위젯·글꼴·스킨 목록
  - `get_planner`: 지금 플래너 보기
  - `build_planner`: 대화로 정한 배치와 스킨으로 바로 만들기·바꾸기. 새 버전으로 저장되고 기록은 그대로
  - `add_goal_plan`: 큰 목표·마일스톤·첫 할 일을 넣고, 원하는 마감과 가능한 날짜, 병목을 돌려줌
  - `add_items`: 할 일(고정 일정 포함)·루틴·페르소나 넣기
  - `get_today`: 오늘 상태 읽기
- **규칙(가이드에 적음):** 먼저 묻고, 계획을 말로 보여 주고, 사용자가 OK하면 만든다. 모르는 사실은 지어내지 않는다.
- 같은 서버라 MOONS 지식 도구도 함께 보인다(정리안은 승인 후 반영).

## 6. 남은 결정

1. 다꾸 재료(스티커 팩)를 직접 그릴지, 작가와 협업할지.
2. 자유 배치 모드를 기본으로 할지(다꾸형), 격자를 기본으로 두고 선택하게 할지(정리형).
3. 플래너를 MOONS와 **별도 브랜드·주소**로 낼지(다이어리 웹), MOONS 안의 Satellite로 둘지.

## 8. "데일리에 체크만 하면 월별·연도별에도 체크되는" 구조 — 레퍼런스와 lit의 설계

**레퍼런스**
- [ClickUp Goals](https://clickup.com/learn/topic/productivity/tools/features/goal-tracking/): 할 일을 목표(Target)에 이어 두면 할 일을 끝낼 때 목표 진행률이 저절로 오른다. 팀·OKR용.
- [Griply](https://griply.app/faq/best-apps-tracking-goals-habits): 개인용. 목표–습관–할 일을 한 계층으로 묶고, 하위 목표 진행률로 상위 목표를 계산([goal targets](https://griply.app/changelog/goal-targets)).
- [Strides](https://www.online-tech-tips.com/6-best-goal-tracking-apps-for-iphone-and-android/): 습관·목표량·마일스톤 트래커, 할 일 연동은 약함.
- 노션 플래너: 데일리 페이지를 월·연 페이지에 **관계(relation)**로 잇고 **롤업·수식**으로 집계, 버튼 자동화로 연결. 강력하지만 사용자가 DB 구조에 맞춰야 한다([판매 템플릿 예](https://kmong.com/gig/601384)).

**lit은 두 가지 롤업을 함께 한다 (둘 다 저장하지 않고 읽을 때 계산 → 고치면 저절로 맞음)**
1. **날짜 롤업(노션의 월·연 페이지 역할)**: 데일리의 할 일·루틴·집중·컨디션·수면이 날짜(`logicalDay`)로 달·해에 들어간다. 월·년 탭: 할 일 완료율, 루틴 달성률(고른 날 기준), 순집중, 평균 컨디션·수면, 기록한 날, 이달 목표별로 끝낸 일. 따로 연결할 필요가 없다.
2. **목표 롤업(ClickUp·Griply 역할)**: 할 일 → 마일스톤 → 연간 목표. 할 일을 적을 때 제목으로 목표가 자동으로 골라지고, 루틴은 목표를 물려받는다. 목표 탭과 월·년 탭에서 진행률이 보인다.

사용자가 보는 건 **데일리 하나**이고, 궁금할 때 월·년·목표 탭을 열면 이미 끝낸 것으로 채워져 있다.
