# v7 M6 보고서 — 대화

## 1. 바뀐 것
- **진입 위치 = 맥락** (4.7): 대화에 `tags`가 남음.
  - 노트(기존 "MOONS에게 묻기")는 노트 태그.
  - 개념 페이지의 `MOONS에게 묻기`는 개념 태그이고, 그 개념이 나온 노트 4개까지 고정.
  - 질문 노트의 `MOONS에게 묻기`는 질문 태그이고, 질문과 재료 노트가 고정.
  - 내 우주에서 달 버튼은 전체 피드백 대화(galaxy 태그)이고, 프로필 맥락을 허용함.
  - 대화 탭에서 새로 시작하면 자유 대화.
- **대상 화면에서도 대화가 보임**: 노트 원문 옆, 개념 페이지, 질문 노트 아래에 "대화" 목록(누르면 그 대화로).
- **대화 목록 필터**: 검색(제목·내용·태그 대상 이름), 시작한 곳(노트·개념·질문·내 우주·자유), 주제(고정·태그 노트의 주제). 목록 항목에 태그 칩.
- **정리하기** (공책 아이콘, `moons_chat_note`): 대화 노트를 만들고, 그 화면으로 이동.
  - 노트 구성: `Entry.kind='chat'`.
    - 원문은 **사용자 발화만**.
    - 무슨 대화였나: AI 층(점선 칸).
    - 다시 찾아볼 것: 고정 노트로 링크.
    - 더 공부할 것: 개념 칩과 열린 질문. 질문마다 `?`를 누르면 질문 노트로 열림.
    - 대화에서 만든 것.
    - 대화 전체로 가는 링크.
  - 비어 있는 칸에는 "없음"이 표시됨.
  - 대화 툴바에 대화 노트 바로가기가 생김(`noteId`).
- **왜소행성 자동 등록**: 더 공부할 것의 개념은 확인 절차 없이 개념 탭에 들어감. 이름이나 별칭이 같으면 기존 개념에 합쳐지고, 개념 페이지가 바로 채워짐.
- **대화 산출물**: `artifacts` 컬렉션에 저장됨.
  - 폼 초안, 정리 틀, 체크리스트, 글이 대상.
  - 새틀라이트 "내가 만든 것"과 대화 노트에 보이고, 이름을 누르면 펼쳐짐.
  - 폼은 `폼으로 등록`을 누르면 내 폼에 추가되고, 이후 폼 링크가 보임.
- **탐색 지도** (4.7.1, 대화 툴바의 지도 아이콘, `moons_explore_map`):
  1. 탐색 분야와 목표 수준을 입력. 노트·개념이 적으면 `!`가 보임.
  2. "내가 아는 것 확인"을 누르면 개념 12~20개가 나오고, 개념마다 설명 가능 / 들어 봄 / 처음 중 하나를 고름.
  3. "지도 그리기"를 누르면 단원별 개념이 나옴.
     - 내 개념 저장소와 진단으로 상태 점이 찍힘(초록·주황·회색).
     - MOONS 지식만으로 들어온 개념은 점선과 `!`로 표시됨.
     - `!`를 모두 확인해야 `지도 확정`이 켜짐.
  4. 확정한 지도는 **기준 지도**가 되고, 개념 페이지에 "아직 다루지 않은 이웃"(같은 단원에서 설명 가능이 아닌 개념)이 생김.
  - 같은 대화에서 대화 노트를 만들면 대화 노트에 탐색 지도 링크가 생김.
- 운영자 모델 표에 대화 노트·탐색 지도 단계가 추가됨.

## 2. 체크리스트 (9.4)
- [x] 개념 페이지에서 시작한 대화에 개념 태그가 붙고, 그 개념 페이지에 대화 1개가 보임.
- [x] 대화 탭 필터: 개념 1 / 질문 0.
- [x] `정리하기`를 누르면 대화 노트 칸 5개가 모두 채워짐(이번 경우 "없음" 0).
- [x] 더 공부할 것의 개념 2개가 개념 탭에 왜소행성으로 들어감(확인 절차 없음).
- [x] 대화 노트 `sentences`는 사용자 발화만 담음.
- [x] 폼 초안이 새틀라이트 "내가 만든 것"에 보이고, `폼으로 등록`이 됨.
- [x] 탐색 지도:
  - 신뢰도 `!`가 표시됨.
  - 진단 → 지도 순서로 진행됨.
  - `!` 3개를 확인하기 전에는 확정이 꺼져 있고, 확인 후 확정되며 저장됨.
  - 개념 페이지에 "아직 다루지 않은 이웃" 1이 보임.
- [x] 서버 테스트 50, 클라이언트 65 통과, 콘솔 오류 없음.
