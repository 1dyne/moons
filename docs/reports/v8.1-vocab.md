## 확인한 것
- 테스트: moons-sync 16, api-server 55 + 통합 22, web 70.
- 로컬 MCP로 요청서 10장 시나리오 전체(개념 8 + 원문/첨삭 노트 + 첨삭 자료)를 propose_batch로 보냄 → 함에 카드 하나, 전체 승인 1번(9개) + 수정본 노트 1번.
- 원문 탭 "Did you heard"/"poilce" 그대로, 완성본 탭 "Did you hear". 링크 27개(careened, careening, swervin', swerving, swerved, jolt, jolted to a stop, skidding, skidded on ice, trudged, crooked, trail, trailing behind, veered …).
- careen 개념 페이지: 내 원문 2문장 + 승인 수정본 1문장, 배지 표시. 폰 화면에서 탭 → 뜻 시트.
- 같은 묶음 재전송 → 중복 없음. add_record 재전송 → 한 번만 저장.

- 7번(망각 곡선 재노출)은 `fixed`/`wrong`이 record 노트의 `missed`에 남으므로 거기서 시작하면 됨.
