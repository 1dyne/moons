# lit 현재 기능 전체 목록 (2026-11-16)

코드(`lib/planner-spec`, `lib/life-contract`, `artifacts/planner`)와 지금 플래너("무명성 플래너" v16)를 보고 정리했다.
**이름이 여러 개인 것은 같은 줄에 모두 적었다.** ⚠는 같은 개념이 다른 곳에 또 있는 것.

---

## 0. 한눈에: 기능을 만드는 방식이 세 세대 겹쳐 있다

| 세대 | 이름 | 어디에 | 지금 쓰이나 |
|---|---|---|---|
| 1세대 | **모듈** (routine · tasks · checkin · timer · goals · condition · sleep · review · personas) | 첫 시작 화면의 예시 틀 4개(하루 정리 · 현실 플래너 · 오늘의 루틴 · 목표 사다리), `catalog.ts` | 새로 시작할 때만 |
| 2세대 | **내장 위젯** (기능 하나 = 위젯 하나, 33종) + **표** + **내 위젯(설명서)** | 꾸미기 → 위젯 목록, `planner_guide` | 지금 플래너 대부분 |
| 3세대 | **만든 위젯** = DB + 부품 + 규칙 (+ 상황·움직임·스티커) | 새 에디터(화면 · 동작 · 저장 칸) | 오늘 일정, 소원 상자 |

3세대 안에도 2세대 위젯을 부품으로 다시 만든 **프리셋**("old" 묶음)이 있다. 그래서 수면·루틴·집중·미션·신호등·영수증·오늘의 나·하루 돌아보기는 **두 벌씩** 있다.

## 1. 화면 (탭·메뉴)

### 1-1. 탭 (지금 플래너)
| 탭 이름 | 종류 | 내용 |
|---|---|---|
| 오늘 | today | 위젯 12개 (아래 3-1) |
| 주간 | week (고정 화면) | 이번 주 7일 계획표 |
| 월 | month (고정 화면) | 이달 한눈에 · 달력 · 연간 |
| 목표 | goals (고정 화면) | 목표 사다리, 진행률, 이뤘어요·포기 흐름, 가능한 날짜·병목 |
| 페르소나 | page | 위젯 5개 (커넥터로는 목록이 안 보여 확인 필요) |
| 상황판 | page | 위젯 6개 (확인 필요) |
| 분석 | insights (고정 화면) | 달성률, 순집중, 컨디션·수면, 시간대별 에너지, 예상 대비 실제 |

탭 종류: today · week · month · goals · insights · page. 고정 화면 탭(주간·월·목표·분석)은 위젯으로도 넣을 수 있다: `week-view`, `month-view`, `goals-view`, `insights-view`. ⚠ 같은 화면이 탭이기도 하고 위젯이기도 하다.

### 1-2. 메뉴 (≡ 오른쪽 서랍)
내 라이브러리(페이지 틀 · 스킨 · 내 위젯) · 위젯 만들기 · 설치한 위젯 · 모드 · 로직(DB·규칙 보기, 내보내기) · 개발자(토큰, 개발 도구) · 설정(시간대, 하루 경계 04:00, 집중 가능 시간)

### 1-3. 그 밖의 화면
첫 시작(빈 노트 / 예시 틀), 꾸미기 에디터(위젯 목록 · 페이지 · 설정 3단), 위젯 설정(두 번 누르기 / ⚙), 만든 위젯 에디터(화면 · 동작 · 저장 칸), 집중 타이머 멈춤 창(컨디션 1~10 + 메모), 목표 이룸 → 성취 기록지 / 포기 → 조정 기록지, 영수증 팝업·보관함, 기상 흐름, 폰 화면(하단 탭, 주 띠, + 버튼)

## 2. 데이터 (무엇이 저장되나)

### 2-1. 기록 종류 (서버 `life_records`, 11종)
| 기록 | 화면에서 부르는 이름 | 주요 칸 | 비고 |
|---|---|---|---|
| task | 할 일 | 제목, 분류(필수/희망사항/여가), 목표 연결, **루틴 연결(routineId)**, 페르소나 연결, 형광펜, 사용자 속성, 계획(시작·끝·예상·고정 일정), 결과(한 일/일부/못 함/미룸/취소, 이유, 한 만큼) | |
| goal | 목표 | 기간(연간/분기/월간/주간/마일스톤), 상태, 마감, 목표량, 회고(실제 시간·임팩트·ROI·다음엔 누가), 키우는 페르소나 | 진행률은 저장 안 함, 계산 |
| project | 프로젝트 | 상태 | 화면에 거의 안 나옴 |
| routine | 루틴 | 제목, 반복(매일/요일/날짜), 방식(그날 고르기/전부), 목표 연결 | **새 에디터의 DB 목록에 없음** |
| session | 집중 세션 | 시작·끝, 할 일, 컨디션, 메모 | |
| condition | 컨디션 / 에너지 | 점수, 때(기상/점검/저녁), 이유, 저하 요인 | |
| sleep | 수면 | 잠든·일어난 시각 | |
| review | 하루 돌아보기 / 회고 | 한 줄 | |
| persona | 페르소나 | 이름, 역할 목록, 월별 상태(Deployed/Attached/Standby)·우선순위 | |
| note | 메모 · 아이디어 · 페이지 · **표의 줄** · 빠른 기록 | | 표 위젯의 줄도 여기 |
| entry | **만든 위젯의 기록** | 타입(DB), 동작 단어, 시각, 값, 속성, 연결 | 3세대 |

| DB | 속성 | 비고 |
|---|---|---|
| 할 일 (기본) | 제목 · 상태 · 분류 · 날짜 · 시작 · 끝 · 예상 · 한 만큼 · 목표 · 못 한 이유 · 형광펜 · 고정 일정 · **루틴에서 옴(체크, 읽기 전용)** · 페르소나 · Role | ⚠ 루틴은 실제로 연결인데 체크 칸으로 보임 |

### 2-3. 표 (2세대, 지금 플래너에 7개)
| 표 | 열 | 겹치는 것 |
|---|---|---|
| 페르소나 현황 | 월, 상태, 우선순위, 이번 달 주력, Role | ⚠ 페르소나 기록의 월별 상태와 같은 정보 |
| 성취 기록지 (자동 기록: 목표 이룸) | 페르소나, 완료일, 실제 시간, 임팩트, ROI, 다음엔 누가, 메모 | ⚠ 목표 기록의 회고(retro)를 복사 |
| 조정·포기 기록지 (자동 기록: 목표 포기) | 페르소나, 완료일, 메모, 상태 | ⚠ 목표 기록의 회고를 복사 |
| 집중 로그 (자동 기록: 세션) | 날짜, 페르소나, Role, 시작, 끝, 분, 컨디션, 메모, 목표 | ⚠ 집중 세션 기록을 복사 |
| 논개매 T 기록 | 장, 소요(분), 컨디션, 메모 | 직접 적는 기록 (표가 맞는 용도) |
| 기출 기록 | 과목, 유형, 풀이(분), 오답(분), 컨디션 | 직접 적는 기록 |
| 소원 상자 | 해금 조건, 조건 유형, 상태(잠김/**해금**/사용함) | ⚠ 새 DB "소원"과 같은 것, 말도 다름 |

### 2-4. 사용자 속성이 정의된 곳
- `taskProps` (플래너 설정): 페르소나(선택 10), Role(선택 33)
- 할 일 DB 속성: 같은 두 개가 id `vw8ry3qe`, `2fle3mjb`로 또 있음 ⚠
- 속성 종류 `role`(페르소나별 역할 2단)이 있지만 Role은 아직 `select`

### 2-5. 그 밖에 저장되는 것
플래너 스펙(위젯 배치·스킨·탭, 버전 16), 내 라이브러리(지금 비어 있음), 집중 가능 시간(요일별 + 예외), 모드(에너지 긴축모드: 에너지 4 이하 → 할 일을 "한 일" 방식으로)

## 3. 위젯

### 3-1. 지금 "오늘" 탭에 있는 것 (12개)
| 제목 | 종류 | 세대 |
|---|---|---|
| 보류된 미션 | carry (어제 못 끝낸 일) | 2 |
| 아침 점검 | checkin | 2 |
| 에너지 신호등 | energy | 2 |
| 오늘의 미션 | mission (순집중 480분 vs 일정 전부, 소원 표의 "잠김→해금") | 2 |
| 집중 | focus | 2 |
| 오늘 일정 | made: 할 일 DB + 체크 목록 부품 | 3 |
| 오늘의 루틴 | routine (그날 고르기) | 2 |
| (제목 없음) | timetable (10분 타임테이블) | 2 |
| 하루 영수증 | receipt | 2 |
| 오늘의 나 | personas | 2 |
| 수면 | sleep | 2 |
| 소원 상자 | made: 소원 DB + 입력 칸 + 열림 카드, 스티커로 붙음 | 3 |

### 3-2. 내장 위젯 전체 (2세대, 33종)
- **할 일·기록:** tasks(할 일) · bullet(빠른 기록) · carry(어제 못 끝낸 일) · list(목록 보기) · table(표) · page(자유 페이지) · pagebox(메모·소원 상자) · review(하루 돌아보기)
- **시간:** focus(집중 타이머) · timetable(10분 타임테이블) · hourly(시간대별 타임라인) · receipt(하루 영수증)
- **몸·마음:** checkin(아침 점검) · condition(컨디션) · energy(에너지 신호등) · sleep(수면)
- **루틴·습관:** routine(오늘의 루틴) · habits(습관 격자)
- **목표:** goals(이어진 목표) · progress(목표 진행률) · dday · mission(오늘의 미션) · wishes(소원 상자)
- **페르소나:** personas(오늘의 나) · persona-board(페르소나 현황)
- **고정 화면을 위젯으로:** week-view · month-view · goals-view · insights-view
- **꾸미기:** text · sticker · tape · image · shape
- **확장:** made(만든 위젯) · custom(내 위젯: 설명서 / 코드)

⚠ 소원이 세 가지 방식으로 있다: `wishes` 위젯, `pagebox`(icon gift), 만든 위젯 소원 상자.
⚠ 루틴이 두 가지로 있다: `routine`(오늘 체크), `habits`(한 달 격자).

### 3-3. 만든 위젯 프리셋 (3세대 에디터의 "새로 만들기")
- **old 묶음 (2세대를 부품으로 다시 만든 것):** 집중 타이머(과목별) · 10분 타임테이블 · 하루 영수증 · 오늘의 미션 · 오늘의 나 · 에너지 신호등 · 오늘의 루틴 · 하루 돌아보기 · 수면
- **new 묶음:** 오늘 일정(할 일 목록) · 희망사항 해금 · 목표 달성 축하 · 뽀모도로 · 물 마시기 · 빈 위젯

⚠ old 묶음의 "오늘의 루틴" 프리셋은 루틴을 **새 DB "루틴"의 선택지**로 만든다. 서버의 루틴 기록(2-1)과는 따로다. 루틴이 세 군데에 있는 셈이다.

## 4. 만든 위젯의 재료 (3세대 문법)

| 재료 | 들어 있는 것 |
|---|---|
| **속성 종류 (12)** | 숫자 · 점수 · 짧은 글 · 긴 글 · 선택 · 여러 개 선택 · 체크 · 날짜 · 시각 · 걸린 시간(분) · 연결 · 상황 |
| **부품 (21)** | 입력: 버튼 · 시작·끝 버튼 · 카운터 · 오늘 체크 · 점수 · 입력 칸 묶음 · 체크 목록 / 시간: 스톱워치 · 타이머 / 계산: 숫자·게이지 · 나눠 보기 / 보기: 목록 · 시간축 · 달력 · 막대 차트 · 카드 · 표 · 10분 타임테이블 · 열림 카드 / 꾸밈: 제목·문구 · 빈 줄 |
| **집계 (8)** | 개수 · 합계 · 평균 · 최대 · 최소 · 연속 일수 · 기록한 날 수 · 마지막 값 |
| **기간 (7)** | 보이는 날 · 오늘 · 이번 주 · 최근 7일 · 이번 달 · 최근 30일 · 전체 |
| **상황 (10)** | 오늘 순집중 · 할 일 다 끝내기 · 정한 시각 전에 다 끝내기 · 오늘 끝낸 할 일 개수 · 오늘의 미션 · 목표 진행률 · 목표 이루기 · 에너지 이상 · 에너지 이하 · DB 합계 |
| **규칙: 언제 (6)** | 항목이 생기면/바뀌면(record) · 항목마다 그 항목의 상황이 되면(item) · 상황이 되면(signal) · 정한 시각(time) · 하루 시작(dayStart) · 기상(wake) |
| **규칙: 하면 (6)** | 만들기 · 고치기 · 조건에 맞는 것 다 고치기 · 알림 · **열기**(지금은 오늘 영수증만) · 움직임 |
| **움직임 (10)** | 반짝 · 통통 · 흔들기 · 둥실 · 두근 · 빙글 · 톡 · 빛나기 · 빵빠레 · 축하 화면 |
| **동작 단어 (8, 화면엔 안 보임)** | 계획함 · 시작함 · 끝냄 · 했음 · 쟀음 · 느꼈음 · 바람 · 적음 |
| **위젯 붙이는 방식** | 그냥 카드 / 스티커·도형·사진으로 붙여 두고 누르면 열기(시트·팝업·페이지), 배지 |
| **디자인** | 부품 그대로 + 색·밀도·모서리 / HTML·CSS·JS(개발자 콘솔) |

### 지금 규칙 3개
1. 영수증: 하루 마침 — 매일 02:00에 → 오늘 영수증 열기
2. 새 소원은 잠김 — 소원이 생기고 상태가 비어 있으면 → 잠김
3. 조건이 되면 열기 — 소원마다 여는 조건이 되고 잠김이면 → 열림 + 반짝 + 알림

## 5. 계산으로 저절로 이어지는 것 (저장하지 않음)

| 원인 | 저절로 바뀌는 곳 |
|---|---|
| 할 일 체크 | 목표 진행률(할 일 → 마일스톤 → 큰 목표), 월간 달성률, 주간 계획표, 미션 "일정 전부", 영수증 |
| 집중 ▶/■ | 타임테이블 칠하기, 순집중, 미션, 영수증, 오늘의 나, 목표 실제 시간, 예상 대비 실제 |
| 컨디션 | 신호등, 분석의 시간대별 에너지 |
| 에너지 4 이하 | 에너지 긴축모드 (할 일 → 한 일 방식) |
| 집중 가능 시간 | 목표의 "이대로면 언제 끝", 병목 달 |

진행률 규칙: 이룸 = 100% → 목표량 있으면 양 기준 → 마일스톤 있으면 무게 평균 → 이어진 할 일 끝낸 비율(이룸 전 최대 90%).
