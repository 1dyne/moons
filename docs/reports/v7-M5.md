# v7 M5 보고서 — 스테이션 · 질문 노트

## 1. 바뀐 것
- **질문 노트** (5.1, `lib/questions.ts`): `Entry.kind='question'`, 제목 = 질문, 원문(body) = 왜 묻나(사용자 말; 없으면 질문 자체). `question = {why, status, subQuestions, answer, origin}`.
  - 상태 4개(열림·진행 중·잠정·닫힘)는 아이콘 버튼.
  - 하위 질문: 상태, 재료(노트·개념, `+`로 검색해 추가), 결정(고른 것·이유·버린 것+왜, 저울 아이콘; 결정하면 열림→잠정).
  - **MOONS 하위 질문 초안**(✦ 버튼, `moons_question_ai`): 3~5개 + 재료 후보(내 노트·개념에서만). 점선 카드·로봇 아이콘 = `layer:'ai'`, ✓ 채택 / ✕ 버리기. 채택 전에는 남은 것에 안 들어감.
  - **남은 것**은 저장하지 않고 계산: 열린(채택된) 하위 질문 + 재료 개념 중 왜소행성.
  - 답(사용자 글).
  - **과정** (시계 아이콘): 변경 기록에서 이 질문 노트가 바뀐 순간만 뽑아 슬라이더로 재생.
  - 재료 노트를 붙이면 내 우주에서 질문↔노트 연결선(links)이 생김. 재료 노트가 있으면 "나란히" 아이콘 → 작업대.
- **질문으로 열기**:
  - 원문 보기에서 문장에 마우스를 올리면 `?` → 그 문장으로 채운 질문 입력창(질문·왜), `origin`(노트·문장) 보존, 질문 노트 상단에 출처 문장 링크.
  - 다음 탐색 카드(M4)의 `질문으로 열기`.
- **스테이션** `/station`: 질문 노트 목록(상태 필터, 하위 질문 수·남은 것 수), 새 질문, 나란히(작업대).
- **작업대 흡수**: 기존 비교 작업대는 `/station/compare?ids=`. `/compare?ids=…`는 그쪽으로 리다이렉트. 노트 탭 "질문" 필터에 질문 노트가 보임.
- 운영자 모델 표에 단계 "질문" 추가.

## 2. 체크리스트 (9.3)
- [x] 문장에서 질문으로 열기 → 질문 노트, origin 보존, 제목이 의문문(문장 끝을 "?"로 바꿔 채우고 사용자가 고침).
- [x] 부록 B를 손으로 입력: 하위 질문 4, 결정 1(ELK / 그룹 중첩 지원 / ✕ dagre — 그룹 표현 불가), 남은 것 계산.
- [x] 남은 것이 계산값: 결정해 잠정 → 4→3, 하위 질문 닫기 → 2, AI 초안은 채택 전엔 0 영향, 채택하면 3.
- [x] 노트 탭 질문 필터에 보임, 재료 노트와 links로 이어짐.
- [x] AI 하위 질문은 점선·로봇 아이콘(`layer:'ai'`), 없는 노트 id·없는 개념은 걸러짐.
- [x] 과정 재생 5단계, `/compare` 리다이렉트, 콘솔 오류 없음. 서버 테스트 49, 클라이언트 65 통과.
