# lit의 자동화는 어떻게 돌아가나

한 줄 요약: **lit에는 기록 저장소가 하나뿐이고, 모든 위젯은 그 저장소를 다른 조건으로 보여 주는 창이다.** 노션의 "workflow master DB 하나 + 화면마다 필터 보기"와 같은 구조다. 그래서 한 곳에서 체크하면 그 기록을 보는 모든 곳이 동시에 바뀐다. 따로 "동기화"하거나 두 번 적을 필요가 없다.

```
                 ┌──────────────────── 기록 저장소 (하나) ────────────────────┐
  체크·입력 ───▶ │ 할 일 · 목표/마일스톤 · 집중 세션 · 컨디션 · 수면 · 루틴 · 페르소나 · 표의 줄 │
                 └──────────────────────────────────────────────────────────┘
                     │ 화면을 열 때마다 계산 (저장하지 않음)        │ 서버가 쓰기 직후 채움
                     ▼                                            ▼
     진행률 · 월/년 요약 · 미션 · 신호등 · 영수증 · 오늘의 나         자동 기록 표 (집중 로그 · 성취 · 조정)
```

## 1. 계산으로 이어지는 것 (항상 최신)

| 내가 하는 일 | 저장되는 것 | 저절로 바뀌는 곳 |
| --- | --- | --- |
| 할 일 체크 | 할 일의 결과 = 완료 | 그 할 일이 이어진 마일스톤 → 큰 목표 진행률, 월·년 "이달 한눈에" 달성률, 주간 계획표, 오늘의 미션 "일정 전부 완료", 목록 보기, 하루 영수증 |
| 과목·할 일 ▶ / ■ | 집중 세션 (시작·끝) | 10분 타임테이블 색칠, 오늘 순집중, 오늘의 미션 "순집중", 하루 영수증, 오늘의 나(페르소나 원형 그래프), 목표의 실제 시간, 예상 대비 실제 |
| 멈출 때 컨디션 | 세션의 컨디션 | 에너지 신호등(불 켜짐·문구·알림), 하루 컨디션, 분석의 시간대별 에너지 |
| 아침 점검 에너지 | 컨디션 기록 | 신호등, 현실적인 집중 가능량 |
| 할 일에 목표 고르기 | 할 일 → 목표 연결 | 목표 진행률·이어진 하루들 |
| 하고 싶은 일(want)로 분류 | 할 일의 분류 | 회색 표시, 달성률·미션에서 빠짐 |
| 페르소나 이번 달 상태 | 페르소나의 월별 상태 | 페르소나 현황 한도 경고 |
| 집중 가능 시간(설정) | 요일별 시간·예외 | 목표의 "이대로면 언제 끝" 날짜, 병목 |

진행률 규칙: 이뤘어요 = 100% → 목표량이 있으면 양으로 → 마일스톤이 있으면 무게 평균 → 아니면 이어진 할 일 중 끝낸 비율(이뤘어요 전 최대 90%).

## 2. 쓰기 직후 채워지는 것 (자동 기록 표)

표 위젯의 설정 "자동 기록"을 고르면 서버가 기록을 저장한 직후 그 표에 한 줄을 넣는다. 앱·Claude·다른 기기 어디서 기록해도 같다.

| 자동 기록 | 언제 | 채우는 열 (열 이름으로 맞춤) |
| --- | --- | --- |
| 집중 세션 | 타이머를 멈출 때 (컨디션을 매기면 같은 줄 갱신) | 날짜 · 할 일 · 페르소나 · 시작 · 끝 · 분 · 시간 · 컨디션 · 메모 · 목표 · 할 일 속성 이름(Role…) |
| 성취 기록 | 목표를 "이뤘어요"로 저장할 때 | 목표 · 완료일 · 실제 시간(분) · 실제 시간 · 임팩트 · ROI · 다음엔 누가 · 메모 · 페르소나 |
| 조정·포기 기록 | 목표를 "포기"로 저장할 때 | 목표 · 날짜 · 메모 · 상태 · 페르소나 |

## 3. 흐름이 있는 것

- **목표 이룸:** 목표 화면 "이뤘어요" → 축하 → 성취 기록지(실제 시간은 집중 기록에서 합산, 임팩트를 고르면 ROI 자동) → 저장하면 성취 기록 표가 있는 탭으로 이동. 이렇게 저장한 목표만 기록에 남는다.
- **목표 포기:** "포기" → 조정 기록지 → 조정 기록 표에 한 줄, 목표에 [다시 목표로] 버튼.
- **소원:** 오늘의 미션에서 순집중 목표 또는 일정 전부 완료 중 먼저 찬 쪽이 이기면 자유시간 타이머가 돌고, 연결한 소원 상자의 소원에 "해금"이 열린다 → 해금 → 사용.

## 4. 노션에서 쓰던 방식과 비교

| 노션 | lit |
| --- | --- |
| workflow master DB 하나 | 기록 저장소 하나 (할 일·목표·세션…) |
| 화면마다 필터 건 링크드 뷰 | 위젯 = 필터 보기 (오늘 일정, 주간 계획표, 목록 보기 위젯의 기간·상태·분류·속성 조건) |
| 롤업·수식 | 진행률·요약 계산 (위 1번) |
| 버튼 → 다른 DB에 페이지 생성 | 자동 기록 표 (위 2번), 목표 이룸 흐름 (위 3번) |
| 타임트래커 버튼 | 과목 타이머 ▶ / ■ → 타임테이블·집중 로그 |

## 5. 표(DB)는 언제 쓰나

할 일·목표·세션처럼 lit이 이미 아는 것은 표로 만들지 않는다(목록 보기 위젯으로 걸러 보면 된다). 표는 lit이 모르는 나만의 기록(기출 점수, 논개매 T 기록처럼 내가 직접 적는 칸)에만 쓴다. 소원은 소원 상자 위젯을 쓴다.
