## 2. 처음부터 바뀌지 않은 축: "저장한 것"과 "아는 것"

모든 버전이 같은 구분을 다른 이름으로 다뤘다.

| 버전 | 저장한 것 | 아는 것 | 넘어가는 행동 |
|---|---|---|---|
| v0.1 | `saved`(메모로만) | 구조화 + 신호 해결 | 사용자가 구조화를 맡김 → 공부해서 업데이트 |
| v6 | 기록 | 확신 + 근거가 맞음 | 대조, 확신 다시 고르기 |
| v7 | `seen` 들어옴 | `explainable` 설명할 수 있음 | 구조화 → 원자료 대조 → 내 말로 설명 |
| v9 | 창고, 뒷면 | 앞면(근거 있는 개념) | `정리`로 페이지 시작 → 스냅샷 분석 → 비교·풀이·설명 |

그리고 **저장에서 멈출지 더 나아갈지는 처음부터 사용자 선택**이었다(v0.1 "구조화는 사용자가 맡길 때만", v9 "창고에만 넣으면 구조화하지 않는다").

## 3. 갈라진 곳 — 지금 쓰기 어려운 이유

1. **"아는 것"을 판정하는 주체가 점점 AI로 넘어갔다.**
   v0.1은 사용자가 업데이트하면 신호가 꺼졌다. v9는 구조화·비교·풀이 근거가 있어야 앞면으로 간다. AI가 안 돌면 전부 뒷면/"형성 중"이라, 사용자가 실제로 공부한 행동(복습, 테스트, 다시 정리)이 화면에 안 남는다.

2. **저장 단위가 사용자 머릿속과 다르다.**
   다인이 생각하는 단위는 **옵시디언처럼 저장되는 개념 노트**다. v9 코드의 단위는 **페이지**이고, 개념은 페이지에서 AI가 뽑은 파생값이다(`conceptKnowledge`가 페이지의 `planetIds`로 개념의 분야를 계산).

3. **모행성의 뜻이 바뀌었다.**
   v0.1: 기록에 붙는 **태그**. 다인의 지금 설명도 같다: **개념에 붙는 속성**이고 Space에서 필터로 고른다.
   v9: **페이지 분류**(상하 계층) — 폴더에 가까워졌고, 학습의 "분야" = 최상위 모행성으로 고정됐다.

4. **같은 구분이 다섯 개 표시로 쪼개졌다.**
   앎의 상태 4단계, 설명 전, 확신 별 5개, 근거 유무(앞면/뒷면), 지형(크레이터·별·안개). "저장만 한 건지, 아는 건지"라는 하나의 질문에 화면이 다섯 가지로 답한다.

5. **전체와 부분이 다른 탭에 있다.**
   Space(전체)와 학습(달·단면도)과 기록(페이지)이 각자 다른 그림이라, 지금 공부하는 것이 전체의 어디인지 이어지지 않는다. 종이 지도의 Top ⇄ Bottom이 없다.

6. **학습 탭에서 학습을 하지 않는다.** 이해도·단계·별점을 읽는 화면이고, 카드를 넘기거나 테스트하는 동작은 다른 화면으로 나가야 한다.

## 4. 다인이 정한 지금의 정의와 연결

| 탭 | 다인 정의 (2026-11-15) | 이전 설계에서 이어받는 것 |
|---|---|---|
| 기록 | 편한 형태로 기록. 개념 단위로 저장(옵시디언처럼). 저장만 할지, 검토·학습 후 재정리할지는 사용자 선택이고, 그 선택이 있다는 걸 moons가 직관적으로 알려줌 | v9 페이지 편집기·창고, v7 개념 노트, v0.1 "구조화는 맡길 때만" |
| 학습 | 기록을 폴더처럼 묶어 한 페이지에 배치. Top(전체 개념 지도) / Bottom(부분 암기)을 설정으로 바꿈 | 종이 지도, v9 캔버스 블록, v8.1 단어 카드 |
| Space | 모행성(개념의 속성)을 필터로 골라 행성으로 봄. 크기 = 쌓인 양, 빛 = 최근 학습 | v0.1 우주 뷰(태그, 크기, 끌어 배치, 근접도), v9 Space 우주 보기 |

**상태가 넘어가는 순간**은 v7에 이미 정의돼 있다: 들어옴(저장) → 정리됨(구조화하거나 다시 정리) → 확인됨(원자료와 대조, 또는 테스트 통과) → 설명할 수 있음(내 말로 설명). v10에서는 AI 없이도 사용자의 행동(다시 정리, 학습 테스트, 내 말 설명)으로 넘어갈 수 있게 하면 된다.
