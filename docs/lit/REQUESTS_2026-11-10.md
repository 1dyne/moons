# 기능 요청 답변 (2026-11-10, lit 개발 세션 → 울림)

"Ante's Orbit"을 만들며 보낸 요청서의 처리 결과. 모두 배포됨. 커넥터는 lit 전용 `…/lit/mcp`와 MOONS 통합 `…/mcp` 둘 다에 같은 도구가 있다(`planner_guide`에 최신 사용법).

## P0

| # | 요청 | 결과 | 쓰는 법 |
| --- | --- | --- | --- |
| 1 | 가용 집중 시간 | 완료 | `set_availability({weekdayMinutes: [일,월,화,수,목,금,토], exceptions: [{date, minutes 또는 hours, note}]})`. 예외만 더할 때 `addExceptions: true`. 앱: 설정 → 집중 가능 시간. 이후 `add_goal_plan`·목표 탭·`get_insights`의 가능한 날짜와 병목이 요일별 시간으로 계산됨(`capacityBasis: "availability"`). 예: `weekdayMinutes: [435,435,180,435,180,435,435]`, 예외 11/21·22 `minutes: 0`, 11/28 발표 |
| 2 | 표 줄 읽기·수정 | 완료 | `list_rows({table: "소원 상자", where: {상태: "잠김"}})` → `update_row({id, cells: {상태: "해금"}})`, `delete_row({id})`. 값은 열 이름으로 주고받음 |
| 3 | 할 일 수정·삭제·이동 | 완료 | `list_tasks({from, to})` → `update_task({id, day: "2026-11-12"})`(이동), `result`, `estimateMin`, `goalId`, `props: {Role: …}`, `category` / `delete_task({id})`. 새벽 재배정은 "읽기 → 옮기기/지우기 → 없는 것만 추가" 순서로 |
| 4 | 집중 세션 → 표 자동 적재 | 완료 (기본 기능) | 표 위젯 설정 "자동 기록 = 집중 세션"(`options.autoLog: "sessions"`). 타이머를 멈추면 한 줄, 컨디션을 매기면 같은 줄이 갱신됨. 열 이름: 날짜·할 일·페르소나·시작·끝·분·시간·컨디션·메모·목표 + 할 일 속성 이름(예: `Role`). 03:00 적재 작업은 더 안 해도 됨. 세션 원본은 `list_sessions` |

| 9 | 페르소나 월별 상태 | 완료 | 위젯 `persona-board`: 이번 달 Deployed/Attached/Standby·우선순위, Deployed가 한도(기본 3, `limit`)를 넘으면 경고(Attached 제외), 역할 편집, 획득한 능력 = 이룬 목표 중 그 페르소나를 키운 것(목표 화면에서 "키우는 페르소나" 선택). AI: `set_persona({name, month, status, priority, roles})` |

## 알아둘 점

- 자동 기록은 서버가 기록을 쓸 때 채우므로 앱·커넥터·오프라인 동기화 어디서 쓴 세션이든 들어간다. 이미 있던 과거 세션은 자동으로 채우지 않는다(필요하면 `list_sessions`로 읽어 `add_items.rows`로 한 번 채우기).
- 에너지 알림은 그 브라우저(설치한 앱 포함)에서 알림을 허용해야 뜬다. 다른 기기로 보내는 서버 푸시는 아직 없다.
- 기존 Role 속성(type select)은 그대로 두고, 2단 계층이 필요하면 새 `role` 속성으로 옮기면 된다(값은 같은 문자열이라 옮겨 적기만 하면 됨).
