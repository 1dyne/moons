# v7 아침 브리핑 · 테스트 안내 (2026-10-24 작업분)

M1~M6 모두 구현해 `main`에 올렸고 Railway 배포도 단계마다 확인함. 단계별 상세는 `docs/reports/v7-M1.md` ~ `v7-M6.md`.
검증은 가짜 AI(고정 응답)로 실제 흐름 + 브라우저 화면까지 했음. **실제 모델 품질은 아직 안 봤음** — 아침 확인의 핵심.

## 2. 테스트 순서 (운영자 계정으로, 약 40~60분)

준비: 설정 → AI 모델에서 단계별 모델을 고를 수 있음(새 단계: 명제 추출·관계 판정·개념·스파크 받아 적기·다음 탐색·질문·대화 노트·탐색 지도). 처음엔 기본값으로 한 바퀴, 그다음 단계별로 바꿔 비교 추천. 30일 사용량 표에서 단계별 비용 확인.

### A. 둘러보기 (M1)
1. ☰ 메뉴: 만들기(기록·대화) / 앎(노트·개념·스테이션) / 보기(내 우주) / 함께·확장(팀·새틀라이트).
2. 새틀라이트에서 일정표 켜고 끄기 → 메뉴에 나타났다 사라짐.
3. `/universe` 주소 → `/galaxy`로 바뀜. 노트 탭 필터(스파크·자료·질문·대화·구조화 전·주제 없음).

### B. 자료 → 정답 지도 (M3)
1. 기록 → 자료 타일 → **PDF를 끌어다 놓기**(텍스트가 있는 PDF, 20MB 이하). 스캔 PDF는 안내와 함께 거절돼야 함.
2. 원문 보기: 상단 `PDF` 칩으로 원본이 열림, 문장 옆 `p.N`.
3. 구조 보기: 섹션마다 짜임 태그와 지도. 순서·인과·문제해결은 왼→오, 주장은 위→아래, 나열은 들여쓴 묶음, 비교는 표.
   - 파란 실선 = 척추, 흐린 점선 = 보조선. 툴바 % = 지도가 근거로 쓴 문장 비율(85% 미만 노랑).
4. 툴바 지도 아이콘 = 전체 지도(섹션 = 묶음). ▶ = 설명 순서 재생(←/→ 키), 걸음마다 근거 문장.
5. **확인할 것**: 원문에 없는 말로 된 노드가 없는지, 근거 문장이 맞는지, 짜임이 맞는지, 빠진 내용.

### C. 개념 (M2)
1. 자료·스파크를 구조화하면 개념 탭에 개념이 생김. 기존 노트는 개념 탭의 ↻(숫자) 버튼으로 일괄.
2. 개념 페이지: 정의·관계 옆 아이콘(펜=내 말, 책=자료, 로봇=MOONS). 주황 `!` = 근거 없는 MOONS 지식 → 눌러 확인.
3. 원문에서 개념 밑줄(점선 = 왜소행성) 누르면 오른쪽 서랍. 구조 화면 노드 패널에 개념 칩.
4. "설명해 보기"로 개념 이름이 제목인 스파크 쓰기. 메모 → "스파크로 올리기".
5. **확인할 것**: 개념으로 올라간 것이 맞는지(일반어가 올라가지 않는지), 같은 개념이 한 페이지로 합쳐지는지, MOONS 정의의 정확도.

### D. 스파크 → 대조 → 다음 탐색 (M4)
1. 그 자료를 읽고 내 말로 스파크를 쓰고 구조화 → 비교 → 원본 고르기.
2. 노드 패널 "내가 이은 것": 내 연결어 그대로. 눈 아이콘 = MOONS 판단(숨김층).
3. 비약은 MOONS 코멘트(더 살펴보기)로 뜸. 같은 단어 두 뜻이면 노드에 보라색 `@`.
4. 비교 탭 아래: 둘 다 있음 / 원본에만 / 내 노트에만 개념, **다음 탐색 카드**(달라짐·빠짐·비약·설명 안 한 개념마다 하나).
5. 노트 상단 상태 칩(들어옴→정리됨→대조됨). 남은 비율 80% 이상이면 "설명할 수 있어요" 버튼.
6. **확인할 것**: 받아 적기가 내 말을 고치지 않는지(G1 덤프로), 다의어·비약을 잡는지, 카드 질문이 쓸 만한지.

### E. 질문 노트 (M5)
1. 원문 문장에 마우스를 올리면 `?` → 질문으로 열기. 또는 카드의 `질문으로 열기`, 스테이션의 `새 질문`.
2. 부록 B 예시를 손으로 입력: 하위 질문 추가, 저울 아이콘으로 결정(고른 것·이유·버린 것), `+`로 재료.
3. ✦ 버튼 = MOONS 하위 질문 초안(점선 카드, ✓ 채택 / ✕ 버리기). 오른쪽 "남은 것"이 바로 바뀌는지.
4. 시계 아이콘 = 과정 재생.

### F. 대화 (M6)
1. 개념 페이지·질문 노트·노트 원문의 `MOONS에게 묻기` → 대화에 태그. 그 화면 아래 "대화" 목록에 나타남.
2. 내 우주에서 오른쪽 아래 달 = 전체 피드백 대화.
3. 대화 툴바 공책 아이콘 = **정리하기** → 대화 노트(무슨 대화였나·다시 찾아볼 것·더 공부할 것·만든 것·내 말).
4. 더 공부할 것의 개념이 개념 탭에 왜소행성으로 들어갔는지. 폼 초안이 있으면 새틀라이트 "내가 만든 것" → 폼으로 등록.
5. 대화 툴바 지도 아이콘 = 탐색 지도: 분야·목표 → 내가 아는 것 확인 → 지도 그리기 → `!` 모두 확인 → 지도 확정. 개념 페이지 "아직 다루지 않은 이웃".

### G. 모델 비교 (선택)
- 골든 파일을 `docs/golden/` 형식(README)으로 하나라도 만들면: `node --experimental-strip-types scripts/eval-structure.mjs --model anthropic:claude-opus-5-5 --runs 3 docs/golden/G2.json` (키는 환경 변수). 지표·흔들림·비용 표가 나옴.

## 3. AI 호출 수 (동작 하나당, 실제 비용은 사용량 표로)
- 자료 구조화: 명제 1~2 + 관계 1 + 개념 2 (+ 첫 비교 때 자료 개념 2)
- 스파크 구조화: 구조 1~2 + 감정 1 + 개념 2 + 받아 적기 1 + 판단 1
- 비교: 문장 1 + 구조 1 + 다음 탐색 1 (+ 보조 원본마다 2)
- 질문 초안 1, 정리하기 1 + 개념 페이지 1, 탐색 지도 진단 1 + 지도 1(deep)
- 운영자가 아닌 사용자의 하루 한도는 "동작" 단위(한 동작 안의 여러 호출은 1회)로 셈.

## 4. 물어볼 것 (모아서)
1. **스파크 지도 방식**: 스파크는 사용자 묶음을 따르는 기존 지도 + 받아 적기 층으로 했음. 스파크도 자료처럼 명제 지도로 다시 그릴지? (M4)
2. **"설명할 수 있음" 확인 방식**: 지금은 남은 비율 ≥ 0.8이면 버튼 한 번. 대신 설명 스파크를 직접 쓰게 할지? (M4)
3. **대화 노트 자동 생성**: 지금은 `정리하기`를 누를 때만. "대화가 끝났을 때" 자동으로 만들려면 끝남 기준(예: 30분 무응답)을 정해 줘야 함. (M6)
4. **질문 제목 다듬기**: 문장에서 질문을 열면 문장+"?"를 사용자가 고침. MOONS가 의문문으로 다듬어 줄지. (M5)
5. **PDF 공백**: PDF 안에 글꼴이 바뀌는 자리의 공백 글자(예 "collider 의")도 원문으로 둠. 지워도 되는지. (M3)
6. **기존 자료 재구조화**: 기존 자료는 다시 구조화해야 정답 지도(v3)가 됨. 일괄로 돌릴지(비용 발생). (M3)
7. **영어 화면 용어**: 영어 화면엔 node/planet 단어가 남아 있음. 영어도 바꿀지. (M1)
8. **다음 탐색 ↔ 기준 지도**: 확정한 탐색 지도를 다음 탐색 카드 계산에도 넣을지(지금은 개념 페이지 이웃에만). (M6)
9. **골든 세트**: G2~G6 중 하나라도 있으면 실제 모델로 9.2 지표를 돌려 M3·M4를 다듬을 수 있음.
