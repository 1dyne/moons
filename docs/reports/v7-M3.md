# v7 M3 보고서 — 구조화 v3 (자료 → 정답 지도)

## 1. 바뀐 것
- **PDF 첨부** (6.4): 자료 타일 화면에 PDF를 끌어다 놓거나 고르면 올라감(20MB까지). 원본 파일은 보관되고 원문 보기 상단 `PDF` 칩으로 열림. 추출 글이 원문(원문 불변 규칙 그대로). 제목·섹션(큰 글자 줄)·문단·쪽 번호를 살림. 반복 머리말·꼬리말·쪽 번호 줄은 뺌. 문장마다 쪽(`Anchor {kind:'page'}`, 원문 인용 옆 `p.N`). 글자 층 없는 스캔 PDF는 "다음 단계" 안내로 거절. `v5/pdf-material.ts`, `POST /api/personal/material-pdf`.
- **정답 지도 파이프라인** (6.1, 자료에만 적용; 스파크는 M4): `lib/server/structure-v3.ts`
  - A 명제 추출(`moons_claims_extract`): 섹션(제목·문장·짜임·신호·비교표) + 명제 `{subj, pred, obj, sentences, kind, marker}`. 검증: 근거 문장 없으면 버림, subj/obj가 근거 문장에 글자 그대로 없으면 버림(띄어쓰기·대소문자만 허용), implied는 담화 표지가 원문에 있어야 함.
  - B 항 정규화: 같은 이름의 항은 한 노드. 개념 컬렉션(M2)과 이어짐.
  - C 관계 판정(`moons_claims_relate`): 닫힌 목록 9개에서 하나 + 방향.
  - D 척추: 섹션 짜임의 관계(순서=sequence, 인과=cause, 문제해결=solution·cause, 비교=contrast·property, 주장=cause·example, 나열=종류·부분·속성·사례)는 `role:'spine'`, 나머지 `cross`. 짜임 null이면 가장 많은 관계.
  - E 배치: 화면에서 ELK. LLM 좌표 없음.
  - F 자기 검증: `analysis.quality` = 명제 수, 근거 문장 비율(coverage), 근거 없는 엣지 수(항상 0), 빠진 문장, 고아 개념, 재시도 여부. 빠진 문장이 15% 넘거나 깨진 명제가 많으면 A를 문제 목록과 함께 1회 재시도하고 더 나은 쪽을 씀.
  - 모든 엣지에 `claimIds`. 설명 순서 `analysis.order` 저장.
- **짜임별 배치**: 순서·인과·문제해결 = ELK 계층(왼→오), 주장 = ELK 나무(위→아래), 나열 = 묶음(들여쓴 나무), 비교 = 표(표가 있을 때). 너무 넓으면 자동으로 위→아래로 바꿈. 섹션마다 형태 버튼(지도·나무·표·줄, 아이콘). 척추선은 파란 실선, 보조선은 흐린 점선.
- **전체 지도**: 섹션이 둘 이상이면 툴바의 지도 아이콘 → 섹션 = ELK 그룹, 섹션 사이 선은 보조선.
- **설명 순서 재생**: 툴바 ▶ → 아래 막대에서 한 걸음씩(←/→ 키, 자동 재생). 걸음마다 선 하나 + 근거 원문 문장(누르면 원문 위치). 지도에서 두 끝이 강조됨.
- **구조 모양 드롭다운 제거**. 분석 기록 목록은 `번호 · 모델 · 날짜`.
- 근거 문장 비율을 툴바에 % 칩으로(85% 미만이면 노란색).
- 운영자 AI 모델 표에 단계 추가: 명제 추출(정답 지도), 관계 판정, 개념.
- `scripts/eval-structure.mjs` (9.2): 골든 파일을 읽어 근거 없는 엣지·명제 커버리지·충실도·관계어·짜임·개념 승격·고아·페이지 채움을 계산, `--model`, `--runs`(흔들림), `--out`. 호출 수·토큰·비용도 표에. 형식은 `docs/golden/README.md`.
- 서버 오류 문구도 한국어로 보이게(errMsg가 번역을 거침). 남아 있던 자료 화면 안내 문구 2곳 제거.

## 3. 비용
- 자료 구조화 1회 = A 1~2회 + C 1회 + 개념 2회. 30문장 넘는 자료는 A를 deep 모델로.
- 실제 사용량은 설정 → AI 모델 아래 30일 표(단계별)에서 예측서와 비교.

## 6. 물을 것
- PDF 추출에서 글꼴이 바뀌는 자리에 PDF가 공백 글자를 넣은 경우(예 LibreOffice 출력 "collider 의")도 원문으로 그대로 둠. 원문 불변을 지키려면 이게 맞다고 봤는데, 이런 공백을 지워도 되는지.
- 기존 자료는 다시 구조화해야 v3 지도가 됨(자동 일괄 재구조화는 하지 않음). 일괄로 돌릴지.
