# v7 M2 보고서 — 개념·메모

## 1. 바뀐 것
- 서버 `v5/concepts.ts`
  - 개념 추출(`moons_concepts_extract`): 노트 한 편에서 명사구 개념, 언급 문장, 설명 여부(explains), 본문 정의(원문 그대로의 일부일 때만), 본문 속 관계. 원문에 없는 개념·문장 번호·정의는 버림.
  - 병합: 이름·별칭으로 노트 사이의 같은 개념을 하나로. 언급마다 `by: user|material`, 노드 id.
  - 개념 페이지 채우기(`moons_concept_page`, 10개씩): 정의, 상위 개념, 대비 1~2, 유사 0~3. 모두 `layer:'ai'`, 근거 없음, 화면에 `!`.
  - 앎의 상태: 들어옴 → 정리됨(구조화된 노트에 있음) → 대조됨(비교된 노트에서 그 문장이 어긋나거나 빠지지 않음) → 설명 가능(내 말로 설명한 스파크까지 어긋남 없음). 비교 결과에 따라 내려가기도 함.
  - 실행 시점: 구조화 직후(그 노트), 비교 직후(원본 자료가 아직이면 원본도), `concepts` 액션(백필·설명 스파크).
- 화면
  - `/concepts` 목록: 종류 필터, 왜소행성(내 말로 설명한 적 없음) 필터, 상태·정렬, 검색, `!` 표시. 아직 읽지 않은 노트 수가 있으면 ↻ 버튼(한 편씩 돌림).
  - `/concepts/:id` 개념 페이지: 정의와 관계에 출처 아이콘(펜=내 말, 책=자료, 로봇=MOONS 지식), `!` 누르면 확인됨, MOONS 관계는 ✕로 지움, ELK로 그린 한 단계 이웃 지도(누르면 그 개념으로), 나온 곳(노트별 문장, 설명 문장은 파란 줄), 메모, "설명해 보기"(개념 이름이 제목인 스파크; 왜소행성이면 강조 버튼).
  - 원문 밑줄: 개념 이름에 밑줄(왜소행성은 점선), 누르면 오른쪽 서랍(정의·관계 요약, 개념 열기).
  - 구조 화면: 노드 글자 안 밑줄, 노드 패널에 개념 칩.
  - 메모: 노트 원문 옆, 개념 페이지. "스파크로 올리기"(노트 메모는 그 노트의 하위 스파크로, 개념 메모는 개념 제목 스파크로). 노트의 하위 스파크도 메모 칸에 같이 보임.
  - `ElkMap` 컴포넌트(elkjs 0.9.3, 지연 로딩): M3 구조 지도에서도 씀.
- 알림 문구 한국어("원본을 비교할 준비가 됐어요.").
- AI 단계 'concepts'가 운영자 모델 선택 표에 추가됨.
